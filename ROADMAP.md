# Public roadmap

The roadmap uses four labels:

- `roadmap: exploring` — we are learning about the problem; there is no delivery commitment.
- `roadmap: planned` — we intend to solve it, but the scope may still change.
- `roadmap: in progress` — implementation is actively underway.
- `roadmap: shipped` — the change is available and links to a release note.

Roadmap issues explain the user problem and expected outcome. Internal tasks, customer data, and private implementation details stay out of this repository.

Dates are shown only when they are real commitments. Absence of a date does not imply low priority, and a roadmap item is not a promise until it ships.
