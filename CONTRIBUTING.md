# Contributing feedback

Before opening an issue, search the existing issues for the same problem.

Good bug reports include:

- what you were trying to do;
- what happened and what you expected;
- the Damdit version (**Settings → About & Support**), your operating system and its version;
- the smallest reproducible example that contains no private data, such as a public website or a small test page.

**Settings → About & Support → Copy Diagnostic Information** copies a redacted summary: app and system versions, the licence state and the status of the latest audit. It never contains website addresses, project names, page content, access keys or account details. Read it before pasting it into an issue.

Please do not attach audit exports, reports or credentials. If a report needs private material, open a minimal issue first, or write to support@damdit.com.

Account, licence and payment questions go to support@damdit.com, not to an issue.
